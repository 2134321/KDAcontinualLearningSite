Kimi-Linear-48B-A3B-Base · hybrid linear attention · 20 KDA + 7 MLA layers

Does a transplanted KDA state carry the document it came from?

Possible evidence for KDA-based continual learning — in a model trained for it. This one wasn’t.

Prefill document A, keep only the 40 MiB KDA recurrent state, discard the KV and short-conv caches entirely, read a different document B, then ask about A. Three experiments, increasingly stringent.

Why KDA, and why this should be possible at all

Kimi Linear interleaves two kinds of layer in a fixed 3:1 ratio: 20 KDA layers (linear attention, constant-size recurrent state) and 7 full-attention MLA layers (quadratic, KV cache that grows with context). KDA extends Gated DeltaNet with per-channel decay, giving each feature dimension its own forget rate.

The reason a transplant is even conceivable is what the KDA update actually is. Per token it applies

St = St−1(I − βtktkt⊤) + βtvtkt⊤

which is exactly one step of online gradient descent on ½∥S kt − vt∥², with βt as the learning rate. The recurrent state is not a cache of past activations — it is a set of fast weights trained by gradient descent during the forward pass (Irie & Schmidhuber, fast weight programming).

If S is weights rather than cache, then S is a checkpoint. Which raises the question this experiment tests: can what the model learned during run A be carried into run B while the KV cache is thrown away entirely? If so, you would have context that never stops accumulating — lossy, but at constant memory (the state is 40 MiB whether A was 1K tokens or 1M) and linear compute. For comparison, the MLA KV cache these runs discard would be roughly 7.9 GB at 1M tokens.

The answer measured here is yes at short lengths, and no at useful ones. A 40 MiB state does carry a real, replicable trace of A across a full cache reset. But the trace thins as the document grows and is undetectable by 16K tokens, while the cost of carrying it holds steady — so the regime where the technique would matter is the regime where it stops working. The headline so far

A 40 MiB recurrent state does carry document-specific information across a full cache reset, and it keeps doing so at every length tested. But that is a claim about what the state contains. Whether transplanting is worth doing is a different comparison — against carrying no state at all — and there the answer turns negative between 1,500 and 4,000 tokens, because carrying any state has a cost that grows with document length while the memory it holds thins. Below the crossover the transplant helps but is dominated by simply pasting the text into context; above it the transplant leaves the model worse off than doing nothing. The strongest single number in the project is the cost, not the benefit: at 50,000 tokens a transplanted state is worth −0.25 nats per token against no state at all, t = −4.46, with every seed agreeing.

What the claim rests on. Knowledge acquired from data A persists across a full cache reset and changes later behaviour — training-free, at inference time. It is specific to A rather than generic (the mismatched control is flat), and it costs nothing on the document actually in context.

What this does not show

  • The B panel rules out gross corruption, but not mild degradation. Accuracy is pinned at 100% in all three conditions and cannot fall further — but the margin is not ceiling-bound. It could have dropped from +17 nats to +5 and still shown perfect accuracy. It rose instead, 17.33 cold to 18.21 warm — and warm and mismatched are identical there (18.206 vs 18.218), so that lift is generic, not document-specific. So a transplanted state does not make the model incoherent, and the position-collision worry does not show up here. What this task cannot speak to is harder capabilities it never exercises — multi-step reasoning, long-range dependency — where a subtler cost could hide.
  • “Document-specific” means fact-specific. A2 shares roughly 45% of its carrier sentences with A, because both sample the same filler pool. That makes the control tighter than a generic one — the effect cannot be explained by A’s state carrying shared register or vocabulary, since A2’s carries those too. But it also narrows the claim: what survives the transplant is information about the planted facts, over and above near-identical prose. An unrelated-prose A2 would support a broader claim on weaker control.
  • This is not retrieval. Warm accuracy on A-facts is 0.566 against 0.486 chance — an eight-point lift on a coin flip. The state carries a detectable trace of A, not A’s contents. You could not look up a planted value with this.
  • The depth effect runs backwards. Facts from the start of A — the ones the forget gates have had longest to decay — transfer best, and it is significant: clustered by seed (early third minus late third, one value per seed) that is +0.320 nats, t(23) = 2.74, p ≈ 0.012, 15 of 24 seeds. The naive item-level test gives r = −0.218, t(286) = −3.77, but treats 12 items sharing a state as independent — do not quote it. The shape is a sharp fall over the first third then a plateau, which looks like primacy rather than decay: facts written into a nearly-empty state may simply get a larger share of it. That is a guess, not a result — this experiment was not built to test it.
  • No ceiling condition was run. Without an Oracle arm — A and B as one uninterrupted sequence — there is no way to say what fraction of the available signal the 40 MiB state preserves.

What this does and does not establish

  • The shape between 600 and 4K is unresolved. 1,500 measures lower than 4,000, which is not physically sensible — their CIs overlap heavily and they are statistically indistinguishable. All that is established is that 600 and 4K show transfer, 16K and 50K do not, and the transition lies somewhere between. Do not read a curve shape into five points at these confidence intervals.
  • The carrier alone halves the effect. At an identical 600 tokens, the synthetic looping carrier of experiment 1 gives +0.396 nats and real Wikipedia prose gives +0.213, with non-overlapping CIs. A repetitive template is far easier to compress, leaving more of a finite state for the planted facts. Experiment 1's headline number is therefore an overestimate of what happens on real text.
  • Planted facts are conspicuous here. A sentence about a pumping station's circuit label sits between unrelated Wikipedia paragraphs, so it is a visible non-sequitur in a way it was not in experiment 1, where facts blended into matching prose. Salience could raise or lower encoding strength and this design cannot separate the two. Experiment 3 removes the issue by scoring real sentences instead of planted ones.
  • 100K tokens would not fit. One-shot prefill OOMs on a 141 GiB card — it asked for 7.07 GiB more than was free. 50K is the ceiling for this hardware without chunking, and chunking would introduce bf16 boundaries in the long arm only, confounding length with segmentation.
  • Only 8 seeds per length. Enough to detect an effect the size of experiment 1's, not enough to rule out a small residual at 16K and beyond. The CI upper bound at 16K is +0.095, so anything above about a quarter of the 600-token effect is excluded — but zero and "small" are not distinguished.

Nothing is planted here. Documents are unbroken corpus prose; the probes are real sentences taken from A itself. The model gets the opening eight words and is scored on the true continuation, so there is no inserted non-sequitur and no forced choice. The number of probes stops being a design limit: 106 at 600 tokens, 1,600 at 50,000.

It separates two questions experiment 2 could only see combined. Does the state carry information about this particular document? — yes, at every length: warm stays above mismatched throughout, +0.054 down to +0.009 nats/token. Is transplanting worth doing? — that is warm against cold, because the alternative to a transplant is no transplant, not an irrelevant one. It is positive at 600 and 1,500 and negative from 4,000 on, reaching −0.253 at 50K.

The two must not be conflated. warm − mismatched compares two states that both pay the cost of being carried, so it can only establish document-specificity. The generic cost itself is mismatched − cold, which grows from −0.016 to −0.262 and is what drags the benefit under water.

What this establishes

  • The cost is the solid finding. warm − cold at 50K is −0.253 nats/token with t = −4.46 and 8 of 8 seeds agreeing. By contrast warm − mismatched only clears the per-seed test at 600 and 1,500. The evidence that carrying a state hurts is much stronger than any evidence that it helps.
  • Document-specificity persists; benefit does not. warm stays above mismatched at every length including 50K — relevant context beats irrelevant context throughout, which experiment 2 could not show past 16K. But that is a statement about what the state contains, not about whether carrying it is worthwhile: both conditions pay the same cost, so the comparison is between two burdened options. Against no state at all, the transplant is a loss from 4,000 tokens on.
  • No depth effect here. Sorting probes by position in A gives no consistent gradient at any length, which does not reproduce experiment 1's primacy result. Either that finding was specific to planted facts, or it does not survive real prose.
  • B-probes are a ceiling. Loss is about −0.01 nats/token because the sentences come from the document sitting in context — the model is close to copying. Detecting damage there needs a task with headroom.
